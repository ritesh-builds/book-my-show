# BookMyShow System Design

A low-level and high-level system design project for a movie ticket booking platform like BookMyShow.

## Overview
This repository contains the architecture, data models, workflows, and implementation details for BookMyShow.

## Key Features to Cover
- Movie, Theatre, and Screen Management
- Show Timings and Dynamic Seating Layouts
- Real-time Seat Locking and Concurrency Control
- Booking and Payment Flow
- Search and Filtering
- Scalability and High Availability Patterns
